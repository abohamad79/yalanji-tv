# شاشة العرض الذكية — M Tech

قائمة المحل على التلفزيون، والتحكم بها من الهاتف. التعديل يظهر على الشاشة خلال أقل من ثانية.

## التشغيل

```bash
npm install
MONGODB_URI="mongodb+srv://..." node server.js
```

البيانات كلها في MongoDB. لا يُكتب أي شيء على قرص الخادم، فلا يهم أن يكون مؤقتًا.

| | |
|---|---|
| الشاشة | `http://localhost:3000/tv/yalanji` |
| اللوحة | `http://localhost:3000/admin/yalanji` |
| كلمة المرور | `yalanji1` — **غيّرها من الإعدادات فورًا** |

افتح الرابطين في نافذتين وغيّر سعرًا من اللوحة. الشاشة تتغيّر وأنت تنظر.

---

## ما بُني وما اختُبر

| | |
|---|---|
| **الدفع الفوري** | Server-Sent Events. الشاشة تعيد الاتصال وحدها عند انقطاع الشبكة |
| **المصادقة** | كلمة المرور مجزّأة بـ scrypt، وجلسة في كوكي HttpOnly تنتهي بعد ١٢ ساعة |
| **مقاومة التخمين** | تأخير ربع ثانية على كل محاولة دخول |
| **التخزين** | MongoDB — الحفظ يكتمل قبل أن يُرسل الردّ، فلا نافذة لضياع تعديل |
| **تنظيف المدخلات** | الأسعار السالبة تصير صفرًا، الأسماء الفارغة تُحذف، الحقول غير المعروفة تُرمى |
| **عزل كلمة المرور** | لا تخرج أبدًا في أي استجابة، ولا يمكن تعديلها عبر حفظ القائمة |

جُرّبت كلها فعليًا: الدخول الخاطئ والصحيح، الوصول بلا جلسة، محاولة حقن كلمة مرور عبر حفظ القائمة، البث المباشر، وإعادة التشغيل مع بقاء البيانات.

## على التلفزيون

الشاشة مبنية بمقاس ثابت ١٩٢٠×١٠٨٠ ثم تُصغَّر لتناسب أي حجم، فلا تنكسر على أي جهاز.

- **الانقطاع** — آخر قائمة محفوظة في المتصفح وتظهر فورًا عند التشغيل
- **الاحتراق** — إزاحة صامتة للوحة كل ٩ دقائق
- **الفيض** — تصغير تلقائي للخط حتى تدخل كل الأصناف، بدل قصّها
- **النوم** — Wake Lock حيث يتوفّر
- **الأعمدة** — ٢ أو ٣ أو ٤، والأقسام تتوزّع تلقائيًا بالتوازن

أفضل عتاد: عصا Android TV بـ ١٥٠–٢٠٠ شيكل مع تطبيق kiosk يفتح الرابط عند التشغيل. متصفح التلفزيون المدمج يعمل، لكنه ينسى الرابط بعد كل إطفاء.

## إضافة محل جديد

في `server.js` داخل `SEED`، أو مباشرة في `data/store.json` والخادم متوقف:

```json
"abu-ali": {
  "title": "مشاوي أبو علي",
  "latin": "ABU ALI GRILL",
  "cols": 3,
  "cur": "₪",
  "menu": [{ "n": "على الفحم", "i": [["شيش طاووق", 62]] }],
  "gone": {},
  "ticker": []
}
```

كلمة مروره تُنشأ تلقائيًا عند أول تشغيل (`yalanji1`) — غيّرها من لوحته.

## النشر على الخادم

**على Render:** Blueprint ← اختر المستودع ← Apply. ثم أضف `MONGODB_URI` في
Environment. الباقة المجانية تكفي لأن البيانات خارج الخادم.

**على VPS:**

```bash
sudo certbot --nginx -d tv.mtech.co.il
MONGODB_URI="mongodb+srv://..." pm2 start server.js --name tv-display
pm2 save
```

في كتلة Nginx — **السطران الأخيران ضروريان**، وبدونهما ينقطع البث كل دقيقة:

```nginx
location / {
  proxy_pass http://127.0.0.1:3000;
  proxy_http_version 1.1;
  proxy_set_header Host $host;
  proxy_set_header X-Real-IP $remote_addr;

  proxy_buffering off;          # البث المباشر لا يعمل بدونه
  proxy_read_timeout 24h;
}
```

## قبل أول زبون بفلوس

**غيّر كلمة المرور الأولية.** كل محل جديد يبدأ بـ `yalanji1` — هذا مقبول أثناء التطوير وكارثة في الإنتاج. اجعلها عشوائية عند الإنشاء وأرسلها لصاحب المحل.

**ركّبها في محل واحد مجانًا أسبوعين.** ستكتشف أشياء لا يظهرها أي اختبار على المكتب: واي فاي المحل يسقط، التلفزيون ينام رغم الإعدادات، صاحب المحل لا يجد اللوحة على هاتفه.

**راقب الشاشات.** حقل `screens` في `/api/:slug/state` يخبرك كم شاشة متصلة. أضف تنبيهًا لنفسك إن انقطعت شاشة زبون أكثر من ساعة — تكتشف العطل قبل أن يتصل بك غاضبًا.

## الخطوة التالية

هذا خادم مستقل يعمل الآن. لدمجه مع `mtech-menu` بحيث تقرأ الشاشة نفس أصناف القائمة الرقمية، الملفات جاهزة في المجلد الآخر: `models/Display.js` و `adapters/menuAdapter.js` وبقيتها.

القرار بينهما:

- **مستقل** — أسرع للبيع اليوم، لكن الأسعار تُدار في مكانين
- **مدمج** — سعر واحد يخدم القائمة والشاشة معًا، ويصبح كل زبون قائمة رقمية حالية زبونًا محتملًا للشاشة بضغطة

ابدأ بالمستقل حتى تبيع أول خمسة، ثم ادمج.
